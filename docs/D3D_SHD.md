# Silent Hill: Downpour — карта XDK Direct3D (базовый XEX 4B4E0823, без TU)

Найдено по образу `image.bin` (снят из rexglue, `tools/imgdump.so`) скриптами `tools/find_d3d.py` и разовыми
сканами. Соответствия сверены с Mass Effect NX (`docs/native-renderer.md`) и DownpourRecomp (адреса TU1,
не наши) — смещения в объекте устройства совпали с обоими.

## Объект устройства

| Что | Значение |
|---|---|
| Глобальный указатель на устройство | `0x8378F690` (164 ссылки в коде) |
| Привязанный вершинный шейдер | `dev+12416` (как в Mass Effect) |
| Привязанный пиксельный шейдер | `dev+12412` (как в Mass Effect) |
| `RB_DEPTHCONTROL` | `dev+10548` (совпало с DownpourRecomp) |
| `RB_BLENDCONTROL0` | `dev+10552` |
| `RB_COLORCONTROL` | `dev+10556` |
| `PA_SU_SC_MODE_CNTL` | `dev+10560` |
| `ALPHA_REF` | `dev+10500` |
| Флаги «грязного» состояния | `dev+16` (64-битные, `oris`/`std` в сеттерах) |
| Указатели кольца команд | `dev+0`, `+8`, `+16`, `+24`, `+32` (сбрасываются в начале каждого draw) |

## Функции

| Адрес | Что это |
|---|---|
| `sub_82D18560` | SetPixelShader: `stw r4, 12412(r3)` + пересчёт `dev+10380` |
| `sub_82D185F0` | GetPixelShader: `lwz r3, 12412(r3)` |
| `sub_82D185F8` | SetVertexShader: `stw r4, 12416(r3)` + `dev+10384` |
| `sub_82D18688` | GetVertexShader |
| `sub_82D1D320` | Draw (303 инструкции), вызовов из RHI больше всего |
| `sub_82D1D828` | DrawIndexed (336 инструкций, 10 аргументов) |
| `sub_82D1DD68` | Draw (261 инструкция) |
| `sub_82D1E180`, `sub_82D1E5F8` | ещё два варианта draw |
| `sub_82D22F10` | публикация отложенного состояния перед draw (зовут все draw) |
| `sub_82D227E8` | применение `PA_SU_SC_MODE_CNTL` |
| `sub_82D20768` | вызывает `VdInitializeRingBuffer` |
| `sub_82D21BD8` | вызывает `VdGetSystemCommandBuffer` и `VdSwap` (представление кадра) |
| `sub_82D30320`, `sub_82D30608` | `VdSetGraphicsInterruptCallback` |
| `sub_82D2FAE8`, `sub_82D2D8B0`, `sub_82D30290` | `VdCallGraphicsNotificationRoutines` |
| `sub_829C6D00` | инициализация RHI UE3 (создание устройства, пишет `dev+10548`) |
| `sub_829C8818`, `sub_829CA948`, `sub_829C8758` | RHI UE3: состояние глубины/трафарета (больше всего записей в `dev+10548`) |
| `sub_829C8A68`, `sub_829C8B80` | RHI UE3: `RB_COLORCONTROL` (альфа-тест) |
| `sub_82D172A0`, `sub_82D17330`, `sub_82D173C0`, `sub_82D17450`, `sub_82D174E0` | SetRenderState для блендинга (`dev+10552`) |
| `sub_832E8270` | `ALPHA_REF` |

Вызывающие draw (RHI UE3): `sub_829C93F0`, `sub_829C9128`, `sub_829C91C0`, `sub_829C9AB0`, `sub_829C9F28`,
`sub_829D2830`.

## Объекты шейдеров в устройстве (XDK держит четыре слота)

| Смещение | Сеттер | Геттер |
|---|---|---|
| `dev+12408` | `sub_82D184C8` | `sub_82D18558` |
| `dev+12412` (PS) | `sub_82D18560` | `sub_82D185F0` |
| `dev+12416` (VS) | `sub_82D185F8` | `sub_82D18688` |
| `dev+12420` | `sub_82D18690` | `sub_82D18720` |

RHI UE3 ставит шейдеры через `sub_829C8B80` (пиксельный: берёт объект из `rhi+4`, зовёт `sub_82D18560`) и
`sub_829C8A68` (`sub_82D184C8` + `sub_82D17630`). Обе читают устройство из `0x8378F690` (в коде `lis r31,-31879;
lwz r3,-2416(r31)`).

## Что ещё нужно найти

- Функция связывания VS+декларация+PS (в Mass Effect `sub_8222F850`) — для захвата оригинального контейнера
  до того, как Direct3D перепишет вершинный шейдер под декларацию.
- CreateDevice и параметры представления (для внутреннего разрешения).
- Смещение контейнера внутри объекта шейдера (в Mass Effect: пиксельный `+0x28`, вершинный `+0x368`).
