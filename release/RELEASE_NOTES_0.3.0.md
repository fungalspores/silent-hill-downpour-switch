# Silent Hill: Downpour 0.3.0

## Главное

- **Чёткие субтитры и UI.** После первого glyph-вызова кадра текстовая цель Scaleform `1040`-pitch и `1280`-pitch композиция переключаются на guest-native образы с сохранением содержимого через blit. При 3D `720x405` область текста переходит примерно с `576x405` на `1024x720`; весь 3D-рендер в 720p не переводится.
- **Новый рекомендуемый режим: `720x405` + FSR 1.** Добавлены промежуточные значения с шагом 80 пикселей: `800x450`, `880x495`, `960x540`, `1040x585`, `1120x630`. Режимы `640x360` и `1280x720` сохранены.
- **Экран настроек:** разрешение и пункт «Качество субтитров». Рекомендуется `720x405` и `чёткие / high`; обычный режим субтитров можно выбрать для меньшей нагрузки.
- **Чистый релизный TOML:** диагностика, capture и trace выключены, журнал пишет только предупреждения.

## Установка / обновление

1. Скопируйте папку `switch/` из архива в корень SD-карты.
2. Установите NSP из `nsp/` через DBI.
3. Запустите игру с HOME. В первые 5 секунд **+** открывает настройки; рекомендуемые значения отмечены на экране.

Игровых файлов в архиве нет: нужна своя копия Xbox 360-версии с проверенным `default.xex` (SHA-256 `c686cbff8facad6fb6b78ed98e5a5a2f4f19337ef83517f56195a56b0db2c8d7`). Библиотека шейдеров для рендера `p2` не нужна. Скомпилированный driver cache и prewarm не распространяются; они создаются локально.

## Проверка

Пользователь подтвердил на Switch Lite (Mariko, Horizon OC CPU 1963 / GPU 1152 / RAM 2333 МГц) чистую пару NRO+TOML, установку NSP, экран настроек, чёткость субтитров и игровую работу. Полное прохождение игры по-прежнему не заявляется.

Контрольные суммы всех файлов находятся в `SHA256SUMS.txt` внутри архива.
